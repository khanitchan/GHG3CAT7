# GHG Scope 3: Employee Commuting Dashboard

เว็บไซต์ Dashboard แบบ Static HTML/CSS/JavaScript สำหรับแสดงข้อมูล GHG Scope 3 — Category 7: Employee Commuting พร้อม Deploy บน Vercel ได้ทันที

## คุณสมบัติ

- KPI: Adjusted GHG, GHG จากแบบสอบถาม, จำนวนผู้ตอบ, ระยะทางเฉลี่ย และ GHG เฉลี่ยต่อคน
- กรองตามสถานที่ทำงาน ฝ่ายงาน รูปแบบการเดินทาง เชื้อเพลิง และ Car Pool
- กราฟรูปแบบการเดินทาง เชื้อเพลิง สถานที่ ยานพาหนะ ระยะทาง และฝ่ายงาน
- Management Insights อัตโนมัติตามข้อมูลที่กรอง
- อัปโหลด CSV เพื่อเปลี่ยนฐานข้อมูลจากหน้าเว็บได้ทันที
- ลากไฟล์ CSV มาวางในพื้นที่อัปโหลดได้
- ตรวจสอบขนาดไฟล์ ตัวคั่นคอลัมน์ และคอลัมน์ที่จำเป็นก่อนโหลด
- รองรับ CSV UTF-8 และ Windows-874 สำหรับไฟล์ภาษาไทย
- ปุ่มกลับไปใช้ฐานข้อมูลเริ่มต้นโดยไม่ต้อง Refresh
- ส่งออกสรุป CSV และ Print/PDF
- Dark mode และ Responsive รองรับมือถือ
- ไม่มี Library ภายนอกและไม่ต้องติดตั้ง `npm`

## การอัปโหลด CSV

1. กดปุ่ม **อัปโหลด CSV** ที่แถบด้านบน หรือพื้นที่อัปโหลดใน Sidebar
2. เลือกไฟล์ `.csv` ขนาดไม่เกิน 25 MB
3. Dashboard จะตรวจสอบและเปลี่ยนฐานข้อมูลทันที
4. เมื่อต้องการย้อนกลับ ให้กด **กลับไปใช้ฐานข้อมูลเริ่มต้น**

ไฟล์อัปโหลดถูกอ่านและประมวลผลภายใน Browser เท่านั้น ไม่ถูกส่งไปยัง Vercel หรือ Server และจะหายเมื่อปิดหรือ Refresh หน้าเว็บ

### คอลัมน์ที่จำเป็น

ไฟล์รูปแบบต้นฉบับรองรับโดยตรง โดยต้องมีข้อมูลต่อไปนี้เป็นอย่างน้อย:

- ระยะทางไป-กลับ เช่น `ระยะทาง ไป-กลับ (หน่วย : กิโลเมตร)` หรือ `distance_km`
- ประเภทยานพาหนะหรือรูปแบบการเดินทาง เช่น `VEHICLE`, `vehicle` หรือ `main_mode`
- Adjusted GHG เช่น `ADJ.(SCALE UP) GHG (TonCo2e)`, `adjustedGHG` หรือ `adjusted_ghg_tco2e`

คอลัมน์สถานที่ทำงาน ฝ่ายงาน เชื้อเพลิง Car Pool Survey GHG และ Working Days ใช้เพิ่มรายละเอียดใน Dashboard หากไม่มี ระบบจะแสดงเป็น `ไม่ระบุ` หรือใช้ค่าเริ่มต้นที่เหมาะสม

## Deploy บน Vercel

### วิธีที่ง่ายที่สุด: Vercel Drop

1. แตกไฟล์ ZIP นี้
2. เข้า Vercel Drop
3. ลากโฟลเดอร์โปรเจกต์หรือไฟล์ ZIP ไปวาง
4. รอระบบ Deploy และรับ URL

### วิธีผ่าน GitHub

1. สร้าง Repository และ Upload ไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ที่ Vercel เลือก **Add New → Project**
3. Import Repository
4. Framework Preset เลือก **Other**
5. ไม่ต้องใส่ Build Command และ Output Directory
6. กด Deploy

## ทดสอบบนเครื่อง

เนื่องจากเว็บไซต์ใช้ `fetch()` อ่าน JSON เริ่มต้น ควรเปิดผ่าน Local Web Server ไม่ควรดับเบิลคลิก `index.html` โดยตรง

```bash
python -m http.server 8080
```

แล้วเปิด `http://localhost:8080`

## ฐานข้อมูลเริ่มต้น

Dashboard อ่านข้อมูลเริ่มต้นจาก `data/commuting.json` ซึ่งผ่านการลบข้อมูลส่วนบุคคลแล้ว ผู้ใช้งานสามารถเปลี่ยนชุดข้อมูลชั่วคราวด้วยฟังก์ชันอัปโหลด CSV โดยไม่ต้องแก้ไฟล์ในโปรเจกต์

## Data Quality

- Main KPI ใช้ค่า Adjusted GHG จากไฟล์ต้นทางหรือไฟล์ที่อัปโหลด
- เดินเท้าที่ไม่มีค่า GHG จะถูกแสดงเป็น 0 tCO2e
- รายการอื่นที่ไม่มีค่า Adjusted GHG จะไม่ถูกรวมในยอด GHG และแสดงใน Data Quality Note
- ระยะทางที่ไม่สามารถอ่านเป็นตัวเลขได้จะถูกกำหนดเป็น 0 km พร้อมแจ้งจำนวนแถวในรายละเอียด Data Quality
